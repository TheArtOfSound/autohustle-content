Install and verify the CLI

Save both downloads in one folder. Open a terminal in that folder and run:

node --version
node sentinel.mjs --self-test
node sentinel.mjs sentinel.json --once

Edit sentinel.json to include your own endpoints. Remove --once to keep monitoring while the process runs. Stop with Ctrl+C.

  • 1–100 endpoints checked sequentially.
  • Default five-minute interval, plus check duration.
  • HTTP status defaults to 200; redirects followed.
  • Each check is printed and appended to a local JSONL log.
  • Logs contain URLs; avoid secrets in URLs and rotate logs as necessary.
