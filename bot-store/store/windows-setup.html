Install Sentinel Studio

Run the monitoring engine independently of your browser. This unsigned, current-user PowerShell setup is an evaluation, not a tested Windows installer. Windows x64, 64-bit Windows PowerShell, internet access and permission to register your own scheduled task are required.

Download setup scriptDownload pinned engine

1. Review the setup

Save the two files together or allow the setup to retrieve the version-pinned engine. Inspect the unsigned script before executing it. The setup obtains the current Node.js 22 x64 runtime from nodejs.org, checks its SHA-256 against the HTTPS release manifest and verifies a valid publisher Authenticode signature. The manifest PGP signature is not independently checked. The Sentinel engine checksum is embedded in the setup.

2. Run on your own computer

Open 64-bit Windows PowerShell in the download directory and run:

.\Sentinel-Setup.ps1

If your execution policy blocks the script, stop and review the policy. Do not bypass organizational security controls. Confirm installation and choose whether to start at sign-in or resume monitoring. Both default to no.

3. Operate and remove

Use the Start menu entries to open the dashboard, stop the engine, check status or uninstall. The current-user interactive scheduled task may restart the engine on failure. It cannot monitor while signed out, asleep or powered off. A console window may appear. Uninstall preserves your monitoring data.

Data folder: %LOCALAPPDATA%\BotAutoHustle\SentinelStudio\data\sentinel-data.
