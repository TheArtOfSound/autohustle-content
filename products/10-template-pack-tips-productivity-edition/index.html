Template 1: The 90-Minute Power Block Planner

When to use: To schedule deep work sessions free from interruptions, ideal for high-focus tasks like writing, coding, or strategic planning.

90-Minute Power Block Planner

Date: [DATE]

Focus Task: [DESCRIBE TASK, e.g., "Draft Q3 report outline"]

Priority Level (1-5): [1 = Low, 5 = Critical]

Pre-Block Setup (10 min before start)

  • [ ] Clear workspace (physical & digital)
  • [ ] Silence all notifications (phone, email, Slack)
  • [ ] Set timer for 90 minutes
  • [ ] Gather all needed materials: [LIST MATERIALS, e.g., "Notebook, reference docs, headphones"]

Block Structure

| Time | Activity | Notes |

|------|----------|-------|

| 0:00 - 0:10 | Warm-up | Review task goals, jot initial ideas |

| 0:10 - 1:30 | Deep Work | Focus solely on task; avoid distractions |

| 1:30 - 1:40 | Short Break | Stand, stretch, hydrate |

| 1:40 - 2:50 | Deep Work | Continue task, maintain focus |

| 2:50 - 3:00 | Wrap-up | Note progress, next steps, and blockers |

Post-Block Review (5 min)

  • [ ] Task progress: [PERCENTAGE COMPLETE, e.g., "60%"]
  • [ ] Key takeaways: [LIST 1-2]
  • [ ] Next action: [DESCRIBE, e.g., "Schedule follow-up block for tomorrow"]
  • [ ] Distractions encountered: [LIST, e.g., "Email pop-up, colleague question"]

Template 4: The SMART Goal Builder

When to use: To set clear, actionable goals using the SMART framework (Specific, Measurable, Achievable, Relevant, Time-bound).

SMART Goal Builder

Goal Title: [GOAL NAME, e.g., "Increase team productivity"]

Specific:

  • What: [DESCRIBE, e.g., "Reduce time spent on low-value meetings"]
  • Why: [REASON, e.g., "To free up 5 hours/week for strategic work"]
  • Who: [INVOLVED PARTIES, e.g., "Team leads and managers"]

Measurable:

  • Key Metrics: [LIST, e.g., "Number of meetings reduced by 30%, time saved per week"]
  • Baseline: [CURRENT STATE, e.g., "10 meetings/week, avg. 1 hour each"]
  • Target: [DESIRED STATE, e.g., "7 meetings/week, avg. 45 minutes each"]

Achievable:

  • Resources Needed: [LIST, e.g., "Meeting templates, stakeholder buy-in, calendar tools"]
  • Potential Challenges: [LIST, e.g., "Resistance from team, time constraints"]
  • Solutions: [LIST, e.g., "Pilot program, clear communication, training"]

Relevant:

  • Alignment with Goals: [DESCRIBE, e.g., "Supports company-wide efficiency initiative"]
  • Impact on Role: [DESCRIBE, e.g., "Allows focus on high-impact projects"]

Time-bound:

  • Start Date: [DATE]
  • Milestones:
  • [MILESTONE 1, e.g., "Week 1: Audit current meetings"]
  • [MILESTONE 2, e.g., "Week 3: Implement meeting templates"]
  • [MILESTONE 3, e.g., "Week 6: Review progress and adjust"]
  • End Date: [DATE]
