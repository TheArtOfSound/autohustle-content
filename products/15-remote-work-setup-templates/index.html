  • Stretch neck, shoulders, and wrists.
  • Standing Break (30 min):
  • Use anti-fatigue mat.
  • Shift weight between legs.
  • Afternoon (1 hr):
  • Alternate between sitting and standing.

Template 6: Home Office Ergonomic Checklist

When to use: To assess and improve your workspace for comfort and long-term health.

```

Home Office Ergonomic Checklist

[Your Name] | [Date]

Desk & Chair Setup

  • [ ] Chair height adjusted so feet rest flat on floor (knees at 90°)
  • [ ] Desk height allows elbows to rest at 90° when typing
  • [ ] Backrest supports lower back (lumbar support)
  • [ ] Monitor at eye level (top of screen at or slightly below eye level)

Monitor & Screen Position

  • [ ] Primary monitor directly in front of you (avoid side positioning)
  • [ ] Distance: Arm’s length away (18-28 inches)
  • [ ] Secondary monitors positioned evenly to avoid neck strain
  • [ ] Screen brightness & contrast adjusted for eye comfort

Keyboard & Mouse

  • [ ] Wrists straight (not bent up/down or side-to-side)
  • [ ] Elbows close to body (90° angle)
  • [ ] Mouse at same level as keyboard to avoid reaching
  • [ ] Use wrist rest if needed (but don’t rest while typing)

Accessories & Extras

  • [ ] Document holder at eye level (if using physical documents)
  • [ ] Footrest used if feet don’t reach floor
  • [ ] Cable management to avoid clutter/tripping
  • [ ] Good lighting (avoid glare on screen)

Stretches & Breaks

  • [ ] Set reminders to stand/stretch every [X] minutes
  • [ ] Keep water bottle nearby to stay hydrated
  • [ ] Consider a standing desk converter if sitting too long

```

Template 11: Remote Work Security Checklist

When to use: To ensure your digital and physical workspace is secure from threats.

```

Remote Work Security Checklist

[Your Name] | [Last Updated: MM/DD]

Device Security

  • [ ] Laptop/PC has full-disk encryption enabled (BitLocker/FileVault)
  • [ ] Strong, unique password for device login ([Use a passphrase])
  • [ ] Two-factor authentication (2FA) enabled on all accounts
  • [ ] Automatic screen lock after [X] minutes of inactivity
  • [ ] Anti-virus/anti-malware software installed and updated
  • [ ] Firewall enabled (Windows Defender/Firewall or equivalent)
  • [ ] Regular backups to cloud/offline storage (automated if possible)

Network Security

  • [ ] Wi-Fi network uses WPA3 encryption (or WPA2 if WPA3 unavailable)
  • [ ] Router admin password changed from default
  • [ ] Guest network disabled or secured separately
  • [ ] VPN active when accessing public Wi-Fi or sensitive data
  • [ ] Router firmware updated to latest version

Account & Data Security

  • [ ] Password manager in use (e.g., Bitwarden, 1Password)
  • [ ] All accounts use unique passwords (no password reuse)
  • [ ] Critical accounts (email, banking, clients) have 2FA enabled
  • [ ] Sensitive files encrypted (e.g., VeraCrypt, encrypted cloud storage)
  • [ ] No sensitive data stored on local devices without encryption
  • [ ] Cloud storage services (Google Drive/Dropbox) use two-factor auth

Physical Security

  • [ ] Workspace locked when unattended (if in shared space)
  • [ ] Sensitive documents shredded or stored securely
  • [ ] No visible notes/passwords near workspace
  • [ ] Webcam covered when not in use

```
